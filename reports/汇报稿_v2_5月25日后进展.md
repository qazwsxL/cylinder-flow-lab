## 1. Phase 1 baseline：32/3 上不够小，64/4 才够（1 分钟，slide 28）

直接看两组数字：

| 网络 | training-time DATA MSE | full-mesh mae_u | speed-normalized 误差 |
|---|---:|---:|---:|
| 32/3（2.8 k params）  | 0.036（rmse ≈ 0.19） | **0.106** | 17.0 % |
| 64/4（14.9 k params） | 0.0008（rmse ≈ 0.028） | **0.0186** | 2.9 % |

→ 32/3 的 BFGS 已经在 plateau 上水平延伸了 200+ 次迭代（slide 29 左下蓝线
斜率接近 0），plateau 0.036 不是 BFGS 没跑够，是 **32/3 的网络容量上限**。
64/4 同协议下 P1 直接降 5.7×，说明这件事完全是 capacity-bound。

**对 consistency 的含义**：P1 不够小，后面 (Y) 判据的分母 mae(P1) 就大，
P2 的容错空间也小。32/3 上的所有 P2 结果都受这个上限制约。

## 2. 三 run 的 loss 折线（1.5 分钟，slide 29）

slide 29 上半画**训练 loss**（DATA + PDE，只画真正进入 loss 的项；strict
consistency 没有 DATA、baseline 没有 PDE，明示标注 OFF）；下半画
**full-mesh CFD-monitor mae_u / mae_v / mean|du,dv|/speed**——这才是真正
反映"场和 CFD 有多近"的轨迹。

下半三张图最重要：

- **P1 baseline（蓝）**：phase-start 1.33 → 单调下降到 0.106。
- **P2 strict consistency（红）**：phase-start 接 P1 ckpt 在 0.106，BFGS
  **把它抬升到 0.339**。
- **P2 all-CFD prio=2（绿）**：phase-start 0.106，BFGS 让它**小幅涨到 0.129**。

**对 consistency 的含义**：strict consistency 虽然 PDE residual 显著下降
（满足 PDE drop ≥ 5×），但 mae 漂移 3.20× **超过 (Y) 判据的 2× 门槛**——
按你确认的强判据，**这个 run 不算 consistent**。prio=2 mae 漂移 1.21× 也
不算 consistent，因为 PDE drop 只有 1.17× < 5×。

## 3. 速度模长归一化的误差（1 分钟，slide 30）

按你说的"v 误差太大就别比 rel_error，直接除根号 u²+v²"——做完之后数字
一下子和肉眼看流场对得上。

CFD 真值统计（7456 cells）：

```
‖u_true‖₂ = 77.17
‖v_true‖₂ =  8.91   ← 只有 ‖u‖₂ 的 11.5%
mean_speed = 0.816
```

旧 rel_l2_v = ‖error_v‖₂ / ‖v_true‖₂ 被 1/0.115 ≈ 8.7× 放大；改成
mean|du,dv| / mean_speed 之后：

| run | 旧 rel_l2_v | 新 mean|du,dv|/speed |
|---|---:|---:|
| P1 baseline (32/3)        | 0.92 | **17.0 %** |
| P2 strict consist (32/3)  | 2.25 | **49.4 %** |
| P2 all-CFD prio=2 (32/3)  | 0.97 | **19.6 %** |
| P2 prio=2 (64/4 scale-up) | 0.16 | **2.7 %** |

**对 consistency 的含义**：旧 rel_l2_v 让 strict consistency 看着"才 2.25"、
prio=2 看着"和 P1 差不多 0.97"，会高估这两个 run 的质量。新归一化让
strict consistency 49% 的误差量级**直接可见**，64/4 的 2.7% 才是真正贴近
CFD。下面所有 consistency 判据都用新归一化重新核对过。

## 4. Matched-colorbar vorticity 对比（1 分钟，slide 31）

老师上次说 vorticity 要在同 colorbar 下比，我在 Oscar 上重跑了三个 ckpt 的
inference（`reports/rerender_vorticity_matched.py`），用 vmin/vmax = ±8
（CFD 真值 peak ≈ ±7.5）渲染。slide 31 现在是真正的 apples-to-apples
四宫格：

- **CFD truth**：两条对称的剪切层 + 中间近壁正负涡量带，|ω|_peak ≈ 7.5。
- **P1 baseline**：vorticity 实际范围只到 ±0.3。小网根本没把高梯度区
  表达出来——速度场拟合凑合是因为速度本身平滑，不是因为模型"懂"尾流。
- **P2 strict consistency**：满屏 ω ≈ ±2 弥漫噪声 + 斜条纹（Fourier
  feature 残留），**没有任何相干尾流结构**——trivial attractor 漂走后场
  退化成 "uniform-flow + 数值噪声"。
- **P2 all-CFD prio=2**：cylinder 附近有清晰双极结构（接近 CFD 尾流前段），
  但远场仍很弱，仍然不足以达到 CFD 的 ±7.5 量级。

**对 consistency 的含义**：strict consistency 的 PDE residual 趋零 **不等于**
和 CFD 一致——vorticity 图直接证伪。这就是为什么 (Y) 必须同时要求 mae
漂移 ≤ 2，**单看 PDE 显著下降会被均匀流骗过去**。

## 5. 用 (Y) 复盘四个 run（30 秒）

最后用 (Y) 判据（**PDE drop ≥ 5× 且 mae 漂移 ≤ 2×**）把四个 run 一字排开：

| run | 网络 | PDE drop | mae 漂移 | (Y) 判据 |
|---|---|---:|---:|:-:|
| P2 strict consistency | 32/3 | huge (→ 0) ✓ | 3.20× ✗ | **× 不 consistent**（trivial attractor） |
| P2 all-CFD prio=2     | 32/3 | 1.17× ✗ | 1.21× ✓ | **× 不 consistent**（PDE 没真降下来） |
| P2 prio=2 scale-up    | 64/4 | **5.97× ✓** | **1.15× ✓** | **✓ consistent** |

只有 64/4 这一行**同时**满足两半。前两个 fail mode 在 32/3 上是**结构性的**
（一个是 trivial attractor，一个是单调 trade-off，slide 26 已经验证），
不是调参能救的。Capacity 才是杠杆。
